Website redesign — pick a direction

Three clean, minimal design systems, each rendering your real content (About, News, Publications) and a live YouTube-embed demo. Open each, compare, and tell me which one to build out — or mix elements between them.

Prototype 1

Editorial

Warm paper, literary serif, a drop-cap, one terracotta accent. Reads like a refined academic journal.
Prototype 2

Swiss / Technical

Stark white, grid columns, hairlines, monospace labels, one signal blue. Precise and engineered.
Prototype 3

Soft

Muted pastels, rounded cards, soft shadows. Warm and approachable, still minimal.

How you'd edit the site (all three share this)

Content stays in plain Markdown, exactly like today's index.md / publications.md. The only new thing is small shortcodes for rich embeds, so you never touch HTML:

{% youtube "aqz-KE-bpKQ" %}   {% figure "cat.JPG" "My cat" %}   {% pdf "cv.pdf" %}

See AUTHORING.md in this folder for the full proposed workflow and the Jekyll includes that power these.
